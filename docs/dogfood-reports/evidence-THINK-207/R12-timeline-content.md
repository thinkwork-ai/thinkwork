## Phase 1: Discovery Workshop — October

**Goal:** Align on customer needs, success criteria, and rollout scope.

| Activity | Output |
|----------|--------|
| Stakeholder interviews | Requirements document |
| Current-state review | Gap analysis |
| Success metrics workshop | KPI baseline |
| Timeline confirmation | Signed project plan |

**Exit criteria:** Approved requirements and committed timeline.

---

## Phase 2: Configuration & Data Migration — Early November

**Goal:** Build the environment and migrate customer data.

| Activity | Output |
|----------|--------|
| Environment provisioning | Staging instance ready |
| Feature configuration | Settings aligned to requirements |
| Data migration | Validated dataset in staging |
| Integration setup | Connected upstream/downstream systems |

**Exit criteria:** Staging environment passes internal QA; data validation complete.

---

## Phase 3: Guided Pilot — Late November

**Goal:** Validate the solution with real workflows in a controlled, two-week window.

| Week | Focus | Activities |
|------|-------|------------|
| Week 1 | Onboarding & first runs | Orientation, supervised usage, daily check-ins |
| Week 2 | Expansion & feedback | Broader use cases, issue triage, feedback synthesis |

**Daily rhythm:** Morning standups, async channel support, end-of-day summaries.

**Exit criteria:** Pilot users complete core workflows; critical issues resolved; go/no-go decision made.

> **Current status:** This is the phase the team is actively planning toward now.

---

## Phase 4: Go-Live & Handoff — December

**Goal:** Launch to full team and transition to steady-state operations.

| Activity | Deliverable |
|----------|-------------|
| Production cutover | Live environment |
| User enablement sessions | Trained end users |
| Runbook delivery | Operational documentation |
| Support handoff | Escalation paths documented |

**Exit criteria:** All users active in production; support team owns ongoing operations.
