Spaces narrow what the tenant platform agent knows for a particular workroom. A support Space works from support runbooks, a customer Space from customer documents, an internal finance Space from finance material — without every other Space inheriting it.

<Aside type="caution">
  **Space-scoped memory banks are retired.** Space memory capture, Space memory
  search, and Space document ingest were removed with the Hindsight memory
  engine. Bedrock AgentCore Memory is the only memory engine and its records are
  requester-scoped: there is no Space bank, no tenant bank, and no promotion
  between scopes.
</Aside>

## What still scopes a Space

Space context now comes from material the Space owns, not from a memory bank attached to it:

- **Space workspace files.** The rendered per-Space workspace is the primary way to give a workroom its own runbooks, policies, plans, and reference documents. Files are versioned in S3 and mounted for work in that Space.
- **Space tools.** Which connectors and approved MCP sources participate, configured on the Space's Tools tab.
- **Space instructions.** The Space's `INSTRUCTIONS.md` shapes how the agent works there.
- **Compiled pages.** Wiki entity, topic, and decision pages remain tenant-scope projections available from any Space.

Good candidates for Space workspace files are exactly the ones that used to be Brain Sources: customer documentation, product or policy runbooks, project plans and operating docs, department-specific source material.

## Where retained memory goes instead

Memory retained from work in a Space is stored against the **requester**, not the Space. Practically:

- A fact a user establishes while working in a Space is available to that user in any Space.
- Knowledge that should be shared across people belongs in Space workspace files or in compiled wiki pages — both of which are visible to everyone with access, and both of which carry provenance.
- There is no "what has this workroom learned" store to query. If a Space needs durable shared knowledge, write it down in the Space workspace.
